Git Smart Rebase

Git Smart Rebase — 5-Stage Safety Pipeline

Auto-stashes pending changes, updates target branch from remote, rebases cleanly, and restores your stash:

  1. Stage & Auto-Stash: Preserves modified and untracked files before switching branches.
  2. Sync Target Branch: Checks out target branch and pulls latest updates from origin.
  3. Return to Working Branch: Switches back to your active feature branch.
  4. Rebase Onto Target: Rebases your commits cleanly on top of the updated target branch.
  5. Restore Stash: Pops your stashed work back into your working tree.
